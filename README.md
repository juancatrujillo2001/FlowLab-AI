# FlowLab AI 🤖

**Framework de agentes de AI para crear Intelligent Business Roles (IBR™) — empleados digitales automatizados para empresas vía WhatsApp.**

## ¿Qué es FlowLab?

FlowLab es una agencia que diseña y despliega agentes de AI que actúan como empleados digitales para empresas. Cada agente se conecta a WhatsApp y otras plataformas para manejar ventas, servicio al cliente y operaciones de forma autónoma.

El sistema se basa en el método **MFA24/7 (Motor de Facturación Automática)** — un proceso de 12 pasos en 4 fases que convierte la información de cualquier negocio en un agente funcional listo para operar.

## Arquitectura del Sistema

El proceso de creación de cada agente sigue este flujo:
INPUT: URL del cliente + redes sociales + documentos
↓
AGENTE 1: Extractor
Scraping + lectura → nombre, servicios,
productos, precios, tono, valores, FAQs
↓
AGENTE 2: Arquitecto del IBR™
Genera → Knowledge Base + Sales Playbook
+ Master Prompt + Reglas de oro
↓
AGENTE 3: Constructor del Workflow
Diseña → flujo conversacional, árbol de
decisiones, escalamiento a humano
↓
OUTPUT: Agente listo para desplegar en WhatsApp.

## Los 3 entregables clave

Cada IBR™ se construye sobre 3 documentos fundamentales:

| Entregable | Descripción |
|---|---|
| **Knowledge Base** | La bóveda de conocimiento del negocio — todo lo que el agente necesita saber para responder preguntas |
| **Sales Playbook** | El protocolo de venta — cómo el agente califica leads, maneja objeciones y cierra |
| **Master Prompt** | El ADN del empleado digital — personalidad, tono, objetivos y reglas de oro |

## Tech Stack

- **Plataforma de agentes:** GoHighLevel (GHL)
- **Canales:** WhatsApp Business API
- **Automatización:** Pipelines y workflows multi-agente
